# עוזר הקניות שלי

מערכת Web אישית לניהול חשבוניות, מוצרים והיסטוריית מחירים.

## הפעלה מקומית

1. התקנת תלויות:

   ```bash
   npm install
   ```

2. העתקת `.env.example` ל־`.env.local` והשלמת פרטי Supabase.
3. הפעלת סביבת הפיתוח:

   ```bash
   npm run dev
   ```

## מסד הנתונים

ה־migration הראשוני נמצא ב־`supabase/migrations`. יש להריץ אותו בפרויקט Supabase לפני חיבור מסכי הנתונים.

המערכת אינה מכילה נתוני דמה. נתונים שיוצגו במסכים יגיעו מ־Supabase בלבד.
